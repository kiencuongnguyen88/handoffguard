# Reduced Variant Admission Gate R001

Any simplified HandoffGuard variant is a challenger, not the default.

## Required evidence before replacement

Compare the challenger against `FULL_BASELINE_SCOPE_R003.md` using the same demo case and unchanged core acceptance expectations.

The challenger may replace the full baseline only if it proves:

1. `MATERIAL_NET_ADVANTAGE` — a meaningful improvement in deadline safety, execution reliability, Bob workflow clarity, demo clarity, or submission quality.
2. `NO_MATERIAL_REGRESSION` — no loss of the core capability set defined in the full baseline.
3. `SAME_OR_STRONGER_PROOF` — executable evidence remains at least as strong.
4. `SAME_OR_STRONGER_BOB_ROLE` — Bob remains a material core component, not a decorative step.
5. `SAME_OR_BETTER_SUBMISSION_READINESS` — the reduced variant does not create new evidence, documentation, screenshot, demo or publication gaps.

Absent these five proofs: `KEEP_FULL_BASELINE`.
