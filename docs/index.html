HandoffGuard

Resume AI coding work only from a verified repository state.

The failure

Agent A leaves a useful checkpoint. Material source changes before Agent B resumes. Restarting everything wastes accepted work; blindly trusting sender-time facts risks stale execution.

The rule

accepted decisions survive the handoff
+
material source facts are verified before resume

Deterministic demo

→ BLOCKED_STALE_HANDOFF
→ PASS_RESUME_BINDING  (fresh-read / re-plan / rebind)
→ FAIL_EXECUTABLE_PROOF
→ PASS_EXECUTABLE_PROOF
→ PASS_CONTINUATION

IBM Bob role

Bob Plan understands the handoff and repo, Bob Agent performs targeted fresh-read/re-plan and the real code repair, and Bob review checks the final diff and evidence. Executable receipts—not AI prose—decide PASS.
